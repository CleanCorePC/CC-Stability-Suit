## English

### About CC Stability Suit

CC Stability Suit is a Windows desktop application designed to help PC owners, gamers, technicians and system builders monitor hardware, test system stability and analyze gaming performance.

The software combines hardware diagnostics, stress testing, real-time monitoring and detailed reporting in one application.

Whether you are troubleshooting a computer, verifying a new build or checking gaming performance, CC Stability Suit provides the tools to evaluate your system.

### Key Features

**Hardware Diagnostics**
- CPU, GPU, RAM and storage diagnostics
- Individual hardware tests and complete system stability testing
- Real-time CPU and GPU temperatures and utilization
- Hardware information and system monitoring
- Detection and reporting of relevant system warnings and errors

**Gaming Performance**
- FPS measurement during gameplay
- Average FPS, maximum FPS, 1% lows and 0.1% lows
- Frametime analysis
- Customizable in-game performance overlay
- CPU and GPU monitoring during gaming sessions

**Reports and Certificates**
- Detailed test results
- PDF and HTML reports
- Test history
- Unique test identification
- Verifiable test certificates
- Reports suitable for hardware servicing and system verification
